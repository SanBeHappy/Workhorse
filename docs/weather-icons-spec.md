# 天气像素图标 · 素材规格

给美术的交付清单，按这份做可以直接替换程序里的矢量图标，不需要再改代码。

## 一、尺寸

| 项目 | 数值 | 说明 |
|---|---|---|
| 设计尺寸（1x） | **16 × 16 px** | 图标框 16px，放在 18px 高的天气行里，上下各留 1px |
| 高清尺寸（2x） | **32 × 32 px** | 系统缩放 200% 时用；建议同时给，等比放大 2 倍、不要插值糊化 |
| 颜色格式 | PNG，**透明底** | 不要带背景色块、不要带阴影（卡片面板本身有抖动纹理，带阴影会脏） |
| 像素网格 | 1px = 1 格 | 不要画半像素、不要抗锯齿；导出处关闭“平滑缩放” |

> 如果想要更“粗颗粒”的像素感，也可以给 **12 × 12**（程序会按 1:1 贴合不缩放），但 16×16 更能表达雨滴/闪电细节，推荐 16。

## 二、数量

### 必需：7 张

| # | 类型 | 文件名 | 画面内容 |
|---|---|---|---|
| 1 | 晴 | `weather_sun.png` | 太阳（8 向或 4 向光芒） |
| 2 | 多云 | `weather_sun_cloud.png` | 云 + 露出的太阳 |
| 3 | 阴 | `weather_cloud.png` | 单朵或双朵云 |
| 4 | 雨 | `weather_rain.png` | 云 + 3~4 条雨滴 |
| 5 | 雪 | `weather_snow.png` | 云 + 3 个雪花点 |
| 6 | 雷 | `weather_thunder.png` | 云 + 黄色闪电 |
| 7 | 雾 | `weather_fog.png` | 3 条横向雾线（可带淡淡轮廓） |

### 可选：再加 2 张（推荐）

| # | 类型 | 文件名 | 说明 |
|---|---|---|---|
| 8 | 毛毛雨 | `weather_drizzle.png` | 细雨点，比“雨”更轻，和 4 区分开 |
| 9 | 冰雹 | `weather_hail.png` | 云 + 圆点冰雹 |

### 可选：夜间版（如果要昼夜区分，7 张全做）

夜间的「晴」换成月亮，「多云」换成月亮+云。命名加 `_night` 后缀：
`weather_sun_night.png`、`weather_sun_cloud_night.png`……共 +7 张。

**结论：最小 7 张，推荐 9 张，加昼夜版是 16 张。**

## 三、配色（沿用现有界面色，别另起一套）

| 用途 | 色值 |
|---|---|
| 太阳 / 光芒 | `#FFC24D` |
| 云 | `#C6CADB`（可加 1 层 `#9AA6BF` 做暗部） |
| 雨滴 | `#6FA8FF` |
| 雪 | `#DCE8FA` |
| 闪电 | `#FFD24D` |
| 夜月 | `#E8EEFB` |
| 描边（可选） | `#1B2340`（和卡片外描边同色，1px，让图标在浅色底上不飘） |

## 四、程序侧现状（供参考，不用你改）

- `weather.py` 里 `WeatherBadge.ICON = 15`，行高 18px；
- 目前是矢量/方块绘制，`draw_icon()` 按 `kind` 分支；
- wttr.in 的天气代码会被归到 7 类：`sun / sun_cloud / cloud / rain / snow / thunder / fog`；
- 换成素材后，程序只按 kind 选图，尺寸由 `ICON` 决定（建议一并改成 16）。

## 五、交付

放在 `assets/weather/` 下，命名如上；1x 与 2x 都要（2x 放同目录，命名 `weather_xxx@2x.png`）。
