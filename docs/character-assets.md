# 角色功能素材清单

角色「大肥鱼」当前在用的全部动画素材，按功能逻辑分组。素材在 `assets/char/`，随程序打包到 `_internal/assets/char/`。

## 规格

| 项 | 值 |
|---|---|
| 画布 | **384 × 384**，透明底 PNG |
| 数量 | **23 张**（历史素材已清理：点击、摸头、长按拎起的 19 张全部移除） |
| 总占用 | 约 **3.1 MB** |
| 绘制 | 按宽度等比缩放到底边居中，画在卡片上沿（角色区高 156px） |

## 一、待机（4 张）

按「多久没人理」递进，鼠标移上来打断一次。

| 文件 | 名称 | 触发逻辑 |
|---|---|---|
| `14_cheek.png` | 托腮 | 默认待机 |
| `18_lean.png` | 倚靠 | 5 分钟没人理 |
| `16_nap.png` | 打盹 | 20 分钟没人理 |
| `17_wow.png` | 惊叹 | 光标移到角色身上，显示 **5 秒**后重置回 `14` |

## 二、久坐提醒（3 张）

按本轮提醒的次数升级，每个表情显示 **3 秒**。

| 文件 | 名称 | 触发逻辑 |
|---|---|---|
| `05_wave.png` | 招手 | 第 1 次提醒 |
| `01_angry.png` | 生气 | 第 2 次提醒 |
| `02_confused.png` | 困惑 | 第 3 次及以后 |

> 点「起来了」清零计数；点「稍后再说」把计数压回 1，下次从招手重新开始。

## 三、下班（1 张）

| 文件 | 名称 | 触发逻辑 |
|---|---|---|
| `06_laugh.png` | 大笑 | 到下班点蹦一下（约 1.2 秒） |

## 四、拖动（3 张）

拖动窗口时按**拖动时长**顺序切换。

| 文件 | 名称 | 触发逻辑 |
|---|---|---|
| `07_stumble.png` | 小碎步 | 拖动 0 ~ 1.4 秒 |
| `08_tumble.png` | 踉跄 | 拖动 1.4 ~ 2.8 秒 |
| `09_faceplant.png` | 拖飞 | 拖动 2.8 秒后；松手后再停 **5 秒**回待机 |

## 五、午休吃饭（6 张）

午休时段自动播放，分前后两段。

| 文件 | 名称 | 触发逻辑 |
|---|---|---|
| `31_cook.png` | 开锅 | 前段第 1 帧（每帧 1.6 秒） |
| `32_scoop.png` | 盛饭 | 前段第 2 帧 |
| `33_serve.png` | 捧碗 | 前段第 3 帧 |
| `34_feast.png` | 猛吃 | 午休满 **2 分钟**后，后段第 1 帧（每帧 1.3 秒） |
| `35_eat.png` | 扒饭 | 后段第 2 帧 |
| `36_full.png` | 吃撑 | 后段第 3 帧 |

## 六、喝水（6 张）

## 已移除的功能与素材

以下几套交互已从产品里删掉，对应素材一并清理（共 19 张）：

| 移除的功能 | 涉及素材 |
|---|---|
| 点击角色换表情（随机舞动 / 连点生气） | `04_wink`、`29_annoyed`、`30_daze` |
| 摸头反应 | `25_shock`、`26_joy`、`27_blush`、`28_love` |
| 长按拎起 | `19_shock`、`20_struggle`、`21_blank`、`22_dizzy`、`23_angry`、`24_cry` |
| 松手摔倒收尾（随速度） | `10_sit`、`11_hurt_sit`、`12_cry` |
| 下班后专用待机 | `15_hi` |
| 早期备用表情 | `03_calm`、`13_peek` |

## 备注

- 所有表情共用同一张画布，绘制时**底边对齐**、水平居中，换图不会跳动；
- `09_faceplant` / `08_tumble` 有单独的垂直偏移修正（`EXPR_OFFSET`），拖飞时把脸抬出来，避免被卡片切掉。
